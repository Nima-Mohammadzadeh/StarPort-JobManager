    Data and backups

    About this

    There is no single database. Each kind of data has one place that is its source of truth, listed below with whether it can be reached and whether the backups cover it. The app database, serial registry, template previews and config.ini are backed up together; files on the share are not, so the share needs its own backup.

    This computer

    About this

    Nobody signs in. When the app needs to know who did something (completing a roll, leaving one in progress, adding a note, creating or completing a job) it asks, with this name filled in so you can just press Enter. It's stored in this browser only.

    Printers

    One printer name per line. Encoders pick one of these on a roll to say where it is running. Running rolls show their printer in the list.

    Rewind page for tablets and phones

    About this

    A page just for the rewind operators. They scan this QR code with the tablet camera, pick a job that is running in encoding, and skim its rolls. It isn't in this menu, and it updates by itself as jobs are created or change.

    Print QR sign Open the page

    Open folder on this PC

    About this

    The app runs on the host PC, so a browser on another PC can't open Explorer by itself. A one-time setup on each PC lets the Open folder button work there. It needs no admin rights and nothing runs in the background. Without it, Open folder copies the path for you to paste into File Explorer.

    Download setup for this PC

    Run the downloaded file once. Windows may warn about a downloaded file; choose More info, then Run anyway. The first time you click Open folder, the browser asks to open Job Manager links. Tick Always allow.

    Shared settings

    Apply to everyone using the app.

    Backups

    About this

    Each backup zips the database, serial registry, serial journal, template previews and config.ini, then checks that the serial history in the zip is complete. With no folder set, backups go to a backups folder next to the app: that is this PC only, so set a folder on the share. A folder here also switches on the serial journal. To restore in an emergency, close the app and drag a backup zip onto restore_backup.bat (see RESTORE.md). A restore never moves serial numbers backwards.

    Bring data over from the old app

    About this

    On the host PC, stop Job Manager and drag the old app's folder onto import_old.bat in this app's folder. It shows a preview first. Serial registries are merged so numbers never go backwards; templates, preview images and jobs come along. Running it twice is safe.
